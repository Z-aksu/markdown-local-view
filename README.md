# Markdown Doc Server CLI

一个简单而强大的 CLI 工具，用于在浏览器中浏览和查看本地 Markdown 文件。它将目录作为树形结构提供服务，并即时渲染 Markdown 文件，类似于本地文档站点。

## 功能特性

- 📂 **树形视图导航**：根据目录结构自动生成侧边栏导航树。
- 📝 **Markdown 渲染**：即时将 Markdown 文件渲染为 HTML。
- 🖼️ **图片支持**：正确解析 Markdown 文件中的相对路径图片。
- 🚀 **零配置**：只需在文件夹中运行命令即可。
- 📦 **NPM 包**：支持全局安装或通过 npx 使用。
- 🧮 **复杂 Markdown**：支持 GFM 表格、任务列表、删除线、自动链接和代码围栏。
- ∑ **数学公式**：通过本地 KaTeX 支持 `$...$`、`$$...$$`、`\(...\)`、`\[...\]` 及常见矩阵/对齐/分段环境。
- 🔗 **文档内链接**：同目录 Markdown 链接在阅读器内切换页签，并保留标题锚点。
- 📱 **响应式排版**：长代码、宽表格和长公式可横向滚动，支持移动端和打印样式。
- 🔽 **已打开页签**：页签超出可视宽度时，右侧显示下拉入口，可查看完整文件名及路径并快速切换；移动端保留横向滑动，隐藏滚动条。
- 📱 **横屏阅读**：手机顶部工具栏最右侧可进入横屏阅读，按钮原位切换为退出，保留文档、页签和阅读位置。点击后先请求全屏，再尝试锁定横屏；方向锁定失败时保留全屏，提示手动旋转手机并开启系统自动旋转。全屏不可用时保留网页内阅读布局。退出后释放本次创建的方向锁定与全屏，并恢复原来的目录状态。电脑窄窗口点击横屏按钮时仅显示提示，不请求全屏，避免窗口闪动。

## 安装指南

### 全局安装

你可以使用 npm 全局安装此工具：

```bash
npm install -g markdown-view
```

### 本地使用

或者直接使用 `npx` 运行：

```bash
npx markdown-view
```

## 使用方法

1. 打开终端或命令提示符。
2. 导航到包含 Markdown 笔记的目录。
3. 运行命令：

```bash
doc-server
```

这将启动一个服务器（默认端口：`51221`）并自动打开本机浏览器。服务器默认绑定到 `0.0.0.0`，因此同一局域网中的设备也可以通过终端输出的 `LAN access` 地址访问。如果指定端口已被占用，程序会自动向后尝试最多 20 个端口，并使用第一个可用端口。

### 选项参数

| 选项     | 别名 | 描述           | 默认值   |
| -------- | ---- | -------------- | -------- |
| `--port` | `-p` | 服务器运行端口 | `51221`   |
| `--host` | `-H` | 服务器监听地址 | `0.0.0.0` |
| `--dir`  | `-d` | 要服务的目录   | 当前目录 |

**示例：**

在端口 8080 上服务特定目录：

```bash
doc-server -d "D:\study-notes\Python" -p 8080
```

如需限制为仅本机访问，可以指定回环地址：

```bash
doc-server --host 127.0.0.1
```

## 渲染约定

- 数学公式使用显式分隔符；普通括号内容不会被猜测为公式。
- 代码块中的 `$`、反斜杠和下划线不会被数学渲染器处理。
- Markdown 原始 HTML 会以文本显示，避免文档内容注入阅读器界面。
- 支持 `.md`、`.markdown`、`.mdown`、`.mkdn`、`.mkd` 和 `.mdwn` 扩展名。

1. 克隆仓库：

   ```bash
   git clone <repository-url>

   ```

2. 安装依赖：

   ```bash
   npm install
   ```

3. 本地链接包进行测试：

   ```bash
   npm link
   ```

4. 运行工具：
   ```bash
   doc-server
   ```
